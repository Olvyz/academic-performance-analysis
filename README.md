# Academic Performance Analysis

Power BI project focused on analyzing academic performance across students, classes, subjects, and academic periods

The report provides an interactive view of academic results, allowing users to explore overall performance, compare classes, review detailed results, and analyze changes in grades over time

## Project Goal

The goal of the project was to build an interactive Power BI report that makes academic performance data easier to explore and understand

The report was designed to support:

* monitoring overall academic performance;
* comparing performance across classes;
* analyzing results by student and subject;
* identifying changes in grades over time;
* exploring detailed academic records

## Report Pages

The report consists of the following pages:

### Academic Performance Overview

Provides a high-level overview of academic results and key performance indicators

### Class Performance

Allows comparison of academic performance across different classes

### Class Details

Provides a more detailed view of class and student-level results

### Analytics & Time Intelligence

Focuses on changes in academic performance over time using DAX time-intelligence calculations

## Tools & Technologies

* Power BI
* DAX
* Power Query
* Data Modeling
* Data Visualization
* Time Intelligence

## Analysis & Features

The project includes:

* interactive filtering and navigation;
* analysis of average grades;
* class and student performance comparisons;
* subject-level analysis;
* KPI-based reporting,
* month-over-month performance analysis;
* year-to-date calculations;
* previous-period comparisons;
* detailed drill-down analysis

Examples of DAX measures used in the report include:

* Average Grade
* Average Grade MoM%
* Average Grade YTD
* Previous Grade
* Total Grades
